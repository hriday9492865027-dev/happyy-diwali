# DEEPAVALI

Personalized, cinematic Deepavali greeting website.

## Start here
1. Read `AGENTS.md`.
2. Read `docs/DEEPAVALI_Complete_Product_Requirements_Document.pdf`.
3. Review `.agents/rules/`.
4. Follow `.agents/skills/deepavali-development/SKILL.md` for the development workflow.

## Approved stack
Next.js, React, TypeScript, Vercel, Neon PostgreSQL, Drizzle ORM, and private Vercel Blob storage.

## Non-negotiable product requirements
- Human-only transparent cutout from visitor photo; remove original scenery.
- Ghost Portrait + Gradual Golden Reveal.
- Cracker bursts emit moving, glowing sparks that drift and fade.
- Mobile-first responsive experience.
- Private media, clear consent, retention, and deletion.
- Graceful no-photo and processing-failure fallbacks.

## Important
This repository package contains agent instructions and project structure guidance, not the application implementation. The PRD PDF must be added to `docs/` before asking the agent to implement.
